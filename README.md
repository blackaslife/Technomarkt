# Technomarkt — E-commerce Web Application

A simulated e-commerce storefront built with vanilla HTML5, CSS3 and JavaScript (ES6+), demonstrating pixel-accurate implementation of a design mockup and fully responsive layout across devices.

🔗 **Live demo:** [blackaslife.github.io/Technomarkt](https://blackaslife.github.io/Technomarkt/)
📦 **Source code:** this repository

## Overview

Technomarkt simulates an online electronics store, focused on translating a Photoshop design mockup into clean, maintainable front-end code with precise attention to spacing, alignment and visual consistency.

## Features

- Product listing pages with card-based layout
- JavaScript-powered image sliders and popups
- Fully responsive design (desktop, tablet, mobile breakpoints)
- Pixel-accurate implementation from a Photoshop mockup, matching spacing, typography and component styling
- Semantic HTML structure for accessibility and maintainability

## Built With

- **HTML5** — semantic markup
- **CSS3** — Flexbox/Grid layout, responsive breakpoints
- **JavaScript (ES6+)** — interactive components (sliders, popups)

## What I Learned

Working from a static design file rather than a live brief taught me how to methodically check spacing, alignment and typography against a source mockup, and how to structure CSS so a design system stays consistent across many product cards without duplicating styles.

## Getting Started

Clone the repository and open `index.html` directly in a browser — no build step or dependencies required.

```bash
git clone https://github.com/blackaslife/Technomarkt.git
cd Technomarkt
open index.html
```
